# Python - Object Relational Mapping

This project introduces database access in Python using:

- MySQLdb (direct SQL queries)
- SQLAlchemy (ORM - Object Relational Mapper)

## Learning Objectives

- How to connect to a MySQL database from Python
- How to execute SQL queries using MySQLdb
- How to use SQLAlchemy ORM
- How to map Python classes to MySQL tables

## Requirements

- Python 3.8+
- MySQL server
- MySQLdb module
- SQLAlchemy module
